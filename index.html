Q3 Chat

Q3 Chat is a personal desktop assistant. Its Windows chat window connects to the owner's private server and a model hosted on Modal. The app can use connected services after the owner grants permission.

Google connections

With approval, Q3 can find and read Gmail messages, prepare email drafts, read calendar events and availability, search contacts, and find or read Drive documents. It can also create text files and permitted copies in Drive. Calendar and Contacts access is read-only; the current Gmail connection has no send-email tool.

Service actions ask for approval, including when the laptop's Full Access option is enabled. Relevant service results can be included in the conversation sent to the private server and hosted model to answer the owner's request.

Who this is for

This app is maintained for personal use. This page is an information and OAuth registration page, not an account-signup or public download service. Q3 is not a Google product or endorsed by Google.
