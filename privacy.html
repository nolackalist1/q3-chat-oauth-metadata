Q3 Chat

Privacy notice

Effective 7 November 2026 · Personal Windows application

This notice describes the current Q3 Chat application maintained for its owner's personal use. It explains how Google data is accessed and processed when the owner connects Gmail, Google Calendar, Google Contacts or Google Drive.

Data and permissions

  • Gmail: account identity, labels, message and thread content, and drafts. The compose permission allows draft management and sending at Google's scope level; Q3's current connection exposes draft creation and reading, with no send-email tool.
  • Calendar: subscribed-calendar details, event content and availability. Access is read-only.
  • Contacts: profile and saved contact details needed for the owner's searches. Access is read-only.
  • Drive: file names and other metadata, permitted document content, and account identity/storage details. Q3 can create text files and make copies where the app's approved file permission allows it. The current connection does not expose sharing changes or deletion.

Q3 requests only the permissions configured for these features. The owner selects connected tools and approves each service action in the app. The app does not run a background mailbox or Drive indexing service.

How data is used and shared

Google data is used to carry out the owner's requests, such as summarizing a message, finding a document, reading availability or preparing a draft. Service results relevant to a request can become part of the chat context sent through the owner's private server to the model hosted on Modal. The owner should approve a read only when that processing is acceptable. OAuth credentials are handled separately and are not included in model prompts.

The laptop uses HTTPS for Google API requests and an SSH connection to the private server. The server uses HTTPS to reach the hosted model. Cloudflare supplies private network transport. Google, Modal, Cloudflare and hosting/network providers process the information necessary to provide their services under their own terms and privacy policies. Encryption in transit does not prevent the receiving server or model from processing the content.

Storage and retention

Q3 keeps the active chat and tool results in the app's memory. It does not automatically save a chat transcript. The owner can export a conversation using Save chat, in which case the exported file remains wherever the owner saves it. Closing the window or starting a new chat clears the app's active conversation; this does not delete an exported file or content deliberately created in a connected service.

OAuth access and refresh credentials are stored locally using Windows account encryption (DPAPI). Service settings and cached tool definitions are stored locally. Q3's diagnostic logs contain event names and timing rather than prompt text or service content. Infrastructure providers may retain operational information according to their own policies; this notice does not promise that third-party infrastructure has zero retention.

Limited Use and model training

Q3 Chat's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy and the Google Workspace API User Data and Developer Policy, including the Limited Use requirements.

Google data is used for the specific user-directed feature. Q3 does not sell it, use it for advertising, or use it to create, train or improve generalized or foundational AI models. Q3 does not share Google data for unrelated human review. This app's model connection is for generating responses to the owner's requests.

Controls, revocation and deletion

The owner can disable a connection in Q3's Plugins settings and can revoke Q3's access in Google Account connections. Disabling a tool does not revoke its Google grant. Revocation prevents future use of that grant; it does not erase messages, files or calendar content in Google, or any copies the owner deliberately exported. Local exported files and Q3 configuration/credential data can be removed from the owner's computer as needed. Never delete a credential by posting its contents in a support request.

Questions and changes

Contact the maintainer with questions about this application. Keep private data and credentials out of public issues. This notice will be updated if Q3's Google data handling changes; the date above identifies this version.
